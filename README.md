# HR Nexus

HR Nexus is an Employee Management System developed as a group project.

## Technology Stack

- React
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL
- Docker

## Local Setup

1. Clone the repository.
2. Copy `.env.example` to `.env`.
3. Copy `backend/.env.example` to `backend/.env`.
4. Install the frontend and backend dependencies.
5. Start Docker Desktop.
6. Run `docker compose up --build`.

## Services

- Frontend: http://localhost:5173
- Backend: http://localhost:5000/api/health
- Database check: http://localhost:5000/api/health/database

## Project Modules

- Authentication and profiles
- Employee and department management
- Attendance management
- Dashboard and leave management
